# Dependency Injection & Service Configuration App (.NET 10)

A robust C# backend project demonstrating core Dependency Injection (DI) principles, service lifecycles, and clean service registration patterns in ASP.NET Core.

## 🚀 Key Concepts Demonstrated
* **Service Lifecycles:** Implementation and comparison of `Transient`, `Scoped`, and `Singleton` service lifetimes.
* **Modular Architecture:** Clean separation of concerns with decoupled service configurations and routing.
* **API Endpoints:** Clean request handling and testing utilities via integrated `.http` files.

## 🛠️ Tech Stack
* **Language:** C# 12 / .NET 10
* **Framework:** ASP.NET Core Web API
* **Tooling:** Visual Studio Code / .NET CLI

## 📂 Project Structure
* `Program.cs` - Application entry point and DI container configuration.
* `Properties/launchSettings.json` - Local environment and IIS/Kestrel profiles.
* `request.http` - Endpoints testing file for quick API validation.
